## ✨ Features

- Plays a video from `res/raw` using `VideoView`.
- Play, pause and seek controls through `MediaController`.
- Uses ViewBinding for the layout.

## 🚀 Run

Open the project in Android Studio and run it. To play a different file, replace `app/src/main/res/raw/test`.

**Tech:** Kotlin · Android SDK · VideoView · MediaController · ViewBinding
